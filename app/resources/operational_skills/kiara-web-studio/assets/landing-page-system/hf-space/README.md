# Landing Cinema Generator

Gerador gratuito de clipes cinematográficos curtos para landing pages.

## API

O endpoint Gradio `generate_cinematic_clip` recebe uma imagem, um preset e a
duração. Ele retorna um MP4 pronto para pós-processamento pelo pipeline local.
