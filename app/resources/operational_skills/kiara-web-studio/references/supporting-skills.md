# Skills de apoio

Definições e referências disponíveis na origem foram copiadas para `references/upstream-skills/<id>/`. Veja os hashes e fontes exatas em `references/source-manifest.json`.

| ID importado | Quando consultar |
| --- | --- |
| sites | Criar/alterar/publicar com o plugin Sites, se ele estiver conectado ao executor atual |
| sites-remix | Derivar um novo site de um site já existente no Sites |
| imagegen | Produzir/editar imagens com a ferramenta de imagem disponível |
| deployments-cicd | Planejar/verificar releases na Vercel |
| vercel-cli | Operar o projeto Vercel correto pela CLI |
| env-vars | Configurar variáveis sem expor segredos |
| domains | Domínios e DNS quando solicitados |
| verification | Conferir o fluxo navegador → API → dados → resposta |
| react-best-practices | Revisar componentes React quando o projeto os utilizar |

Leia o `SKILL.md` da referência escolhida e apenas os recursos necessários. Essas cópias são instruções de apoio, não plugins instalados dentro da Kiara. Disponibilidade de ferramentas, permissões, autenticação e capacidade de publicar precisam ser verificadas no ambiente que executar a tarefa. Não declare um plugin ou serviço ativo apenas por existir uma referência no acervo.
